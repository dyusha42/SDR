# Производственная практика — Software Defined Radio

> **Выполнил:** Золотухин А. А.

---

## О репозитории

Репозиторий содержит материалы, отчёты и flowgraph-файлы GNU Radio,
подготовленные в ходе производственной практики по направлению SDR.

### Используемое оборудование и ПО

- Adalm Pluto SDR
- GNU Radio Companion (GRC)
- Libiio / SoapySDR *(начиная с занятия 3)*
